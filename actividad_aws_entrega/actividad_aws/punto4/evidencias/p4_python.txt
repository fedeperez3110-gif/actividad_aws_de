1) Amigos de amigos de Ana que todavía no conoce (2 saltos por CONOCE)
======================================================================
  MATCH (a:Persona {nombre: 'Ana'})-[:CONOCE]-(amigo:Persona) WITH a, collect(amigo) AS amigos MATCH (a)-[:CONOCE]-(intermedio:Persona)-[:CONOCE]-(sugerido:Persona) WHERE sugerido <> a AND NOT sugerido IN amigos RETURN sugerido.nombre AS sugerido, collect(DISTINCT intermedio.nombre) AS a_traves_de ORDER BY sugerido

2) Personas de empresas ubicadas en Bogotá y sus tecnologías (Ciudad <- Empresa <- Persona -> Tecnología)
======================================================================
  MATCH (c:Ciudad {nombre: 'Bogotá'})<-[:UBICADA_EN]-(e:Empresa)<-[:TRABAJA_EN]-(p:Persona)-[s:SABE]->(t:Tecnologia) RETURN e.nombre AS empresa, p.nombre AS persona, collect(t.nombre + ' (' + s.nivel + ')') AS tecnologias ORDER BY persona
  ---
